**AetherMind AI** is a state-of-the-art, feature-rich web application built with React, Vite, and custom Vanilla CSS. Featuring a futuristic cyberpunk dark-mode glassmorphism interface, multi-persona AI model switching, an interactive live code preview sandbox, voice dictation/speech synthesis, chain-of-thought reasoning, and persistent chat management.

---

## 🚀 Key Features

### 1. 🤖 Multi-Persona AI Engine
Switch between specialized AI personalities anytime:
- **⚡ Aether Core**: Full-stack senior dev companion & general intelligence.
- **🛡️ CyberPulse**: Systems security, CLI diagnostics, & Linux hardening expert.
- **✨ Aura Creative**: UX storyteller, brand copywriter, & poet.
- **📊 Athena Synth**: Strategic executive synthesizer & comparative data analyst.

### 2. 🎨 Interactive Live Code Canvas Drawer
- Any HTML, CSS, or JS snippet generated by the AI includes a built-in **"Open Canvas"** launcher.
- Renders web applications live in an isolated side drawer iframe.
- Allows real-time code inspection, previewing, and refreshing.

### 3. 🌐 Web Search & 🧠 Chain-of-Thought Reasoning Modes
- **Web Search Mode**: Simulates real-time information retrieval across live web sources.
- **Reasoning Mode**: Collapsible thought process box displaying step-by-step analytical reasoning before presenting final answers.

### 4. 🎙️ Voice & Multimodal Capabilities
- **Speech-to-Text (STT)**: Dictate prompts hands-free using Web Speech Recognition.
- **Text-to-Speech (TTS)**: Listen to AI responses aloud via Web Speech Synthesis.
- **Image Attachments**: Attach image files to your prompts with instant thumbnail previews.

### 5. 🎨 Custom Themes & Cloud API Key Integration
- **4 Custom Themes**: Cyber Neon, Deep Space, Emerald Matrix, and Sunset Amber.
- **Google Gemini API**: Option to input your own Gemini API key for cloud AI generation, or use the intelligent built-in offline streaming engine out-of-the-box.
- **Local Storage**: All conversations, custom themes, pinned threads, and preferences persist locally in browser storage.

## 🛠️ Technology Stack

- **Frontend Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (Custom Properties, Glassmorphism, Animations, CSS Grid & Flexbox)
- **Icons**: Lucide React Icons
- **Math Rendering**: KaTeX
- **Audio & Speech**: Web Speech API (SpeechRecognition & SpeechSynthesis)
- **Interactive Feedback**: Canvas Confetti

## 📦 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/aethermind-ai-chatbot.git
   cd aethermind-ai-chatbot
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:5173/`.

4. **Build for Production**:
   ```bash
   npm run build
   ```
